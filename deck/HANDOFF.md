# X17 n_TOF Feb/May 2026 Status Deck — Summary & Handoff

_Prepared June 2026._

## What was built

**`deck/X17_nTOF_Feb_May_2026_Status.pptx`** — a 33-slide 16:9 PowerPoint built with
python-pptx, generated from the documentation in this directory.

Framing (per request): the Feb & May runs were **technical tests** of whether the
high-energy X17 measurement is possible against the "gamma flash" — the relativistic
particles from the proton bunch on the Pb target arriving in EAR2 all at once, which
saturates ("blinds") the **DREAM DAQ**. None of the mitigation ideas worked out; the
thermal-neutron measurement is the viable path for July.

### Narrative arc
1. Title
2. Context — the X17 measurement and the gamma-flash / DREAM-saturation problem
3. The core problem — flash blinding DREAM (4-panel HV progression)
4. **February** divider → setup sketch → "DREAM saturates before efficient" →
   smaller drift gap helps → but costs tracking → marginal best case (He/Eth 6 mm) →
   "what we understood" summary
5. **May** divider → setup sketch → 4096 DAQ bug found & fixed → three flash-mitigation
   ideas (Al plate, mesh injection, neon), none worked → pivot to thermal trigger →
   gas comparison
6. Bottom-line summary
7. **Backup** (15 slides): ATOMKI motivation, flash scope/waveforms, high occupancy,
   the clean thermal track ("what we *can* see"), target comparisons, neon event,
   Sr-90 spectrum, EAR2 photo, Feb gas/run tables, May issues table, July trigger
   concept, roadmap.

### Overhead setup sketches
Generated by `deck/make_setup_sketches.py` (matches the `plot_geometry.py` style/palette):
- **February** — single MX17 MM (40×40) + SiPM wall (50×50) behind, ~20 cm from beam.
- **May** — two MMs at 90°; SiPM wall behind Det-3, a GDD scintillator (30×30) behind
  each. Used **30×30 cm** for the scintillators (from the logbook: GDD borrowed two
  30×30 cm scints), rather than the 25×30 fallback.

## How to rebuild

Use the project venv (NOT system python):

```bash
PY=~/PycharmProjects/nTof_x17/venv/bin/python
cd ~/Downloads/may_feb_results/deck
$PY make_setup_sketches.py     # regenerate setup sketches → assets/
$PY build_deck.py              # rebuild the .pptx
```

To re-render for review:

```bash
libreoffice --headless --convert-to pdf X17_nTOF_Feb_May_2026_Status.pptx --outdir /tmp/deckrender
```

Editing content: slide text/structure lives in `build_deck.py` (linear, top-to-bottom).
Figures are referenced by filename from `assets/`; swap a file or change the `A("...")`
reference to change a figure.
